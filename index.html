About

I am a Team Lead and Full-Stack Software Engineer with 13+ years of experience designing and delivering enterprise software platforms. My core engineering background spans C#, ASP.NET Core, Angular, SQL Server and Java.

At DataPath Ltd., I lead the technical direction of the RK.Web platform across RK.Web.Client, RK.Web.Backend and RK.Web.Lib. My responsibilities include architecture, technical design, implementation, code quality, performance, mentoring and cross-team technical collaboration.

Technical Leadership

Architecture & Technical Decisions

I focus not only on which technology to use, but also on the engineering problem it solves and the trade-offs behind the decision.

Micro-frontends Independent application ownership and deployment. Angular micro-frontends with shared libraries.
Shared UI Library Consistent UX and reduced duplicated implementation. Reusable versioned component packages.
Microservices Separate business capabilities and service boundaries. Independent .NET backend services.
Clean Architecture Maintainability and separation of responsibilities. Domain, application, infrastructure and API boundaries.
CQRS Separate read and write application workflows. Commands and queries using MediatR.
OpenAPI Reliable frontend/backend API contracts. Generated TypeScript clients from API definitions.
Bearer Authentication Authentication across distributed applications. JWT access tokens with refresh-token rotation.
Reusable Engineering Reduce duplicated solutions across teams. Shared libraries, components and common patterns.
