About

At DataPath Ltd., I lead the technical direction of the RK.Web platform, covering software architecture, technical design, implementation, code quality, performance and mentoring. On the frontend, I work with Angular Standalone Components, Micro Frontends, Module Federation, component libraries, shared libraries and reusable UI patterns that support independent development across teams.

On the backend, I work with ASP.NET Core, REST APIs, Clean Architecture, Domain-Driven Design, CQRS, Microservices, distributed systems, authentication, caching and SQL Server.

I also actively practice AI-assisted software engineering, using tools such as Claude and other AI coding assistants for code generation, refactoring, debugging, architecture exploration, documentation and rapid prototyping. I focus on combining AI-assisted development with engineering principles, code review, testing and architectural discipline rather than treating AI-generated code as a replacement for engineering judgment.

Earlier in my career at DataPath, I contributed to the Unify.Backend platform, working on business modules, API services and Windows service applications. I enjoy exploring modern software engineering practices, AI-native development workflows and scalable architecture while helping teams adopt practical, maintainable and future-ready solutions.

Featured work

Current team-lead scope at DataPath Ltd.: coordinating RK.Web.Client, RK.Web.Backend and RK.Web.Lib for a retirement-plan platform serving participants, sponsors and advisors.

  • Leadership: lead the development direction across RK.Web.Client, RK.Web.Backend and RK.Web.Lib, helping the team keep frontend, backend and shared-library contracts aligned.
  • Backend: three .NET 8 microservices using Clean Architecture and CQRS (MediatR), with FluentValidation pipeline behaviours, Repository/Unit of Work and EF Core on SQL Server.
  • Frontend: three independently deployable Angular 21 micro-frontends built from standalone components.
  • Design system: an in-house UI library of 30+ components (forms, modals, charts, grids, tabs, wizards, PDF/Excel export), published as versioned packages.
  • Security: Entra External ID login exchanged for a custom JWT session, with httpOnly refresh-token rotation. Led the migration from cookie-based to bearer-token auth.
  • PII protection: middleware that encrypts sensitive request parameters automatically (AES-256), configured per service.
  • Delivery: TypeScript clients generated from OpenAPI, Docker images deployed to AKS, with Serilog and Prometheus for observability.
