Featured work

A retirement-plan web platform for plan participants, sponsors and advisors, built at DataPath Ltd. (2024 – present).

  • Backend: three .NET 8 microservices using Clean Architecture and CQRS (MediatR), with FluentValidation pipeline behaviours, Repository/Unit of Work and EF Core on SQL Server.
  • Frontend: three independently deployable Angular 21 micro-frontends built from standalone components.
  • Design system: an in-house UI library of 30+ components (forms, modals, charts, wizards, PDF/Excel export), published as versioned packages.
  • Security: Entra External ID login exchanged for a custom JWT session, with httpOnly refresh-token rotation. Led the migration from cookie-based to bearer-token auth.
  • PII protection: middleware that encrypts sensitive request parameters automatically (AES-256), configured per service.
  • Delivery: TypeScript clients generated from OpenAPI, Docker images deployed to AKS, with Serilog and Prometheus for observability.

This is client work, so the source code is private. The diagram shows only the architecture.
